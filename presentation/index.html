SLIDE 04

How OpenCV Works: Image Representation

Images are multi-dimensional numerical matrices stored in memory.

The BGR Matrix Paradigm

Unlike standard web RGB order, OpenCV reads color images in BGR (Blue, Green, Red) channel order by default!

Matrix Dimension Structure:

img.shape = (Height, Width, Channels)
  • Height: Number of pixel rows
  • Width: Number of pixel columns
  • Channels: 3 for BGR/RGB, 1 for Grayscale
  • Data Type: np.uint8 (values 0 to 255)

Interactive Pixel Inspector

Hover over pixels to inspect BGR intensity matrices:

Selected Pixel: (x: 0, y: 0) | BGR: [0, 0, 0]

edge_pipeline.py OpenCV 4.14 
import cv2

# 1. Load Input Image
img = cv2.imread("input.jpg")

# 2. Convert BGR to Grayscale for simpler intensity analysis
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 3. Apply Gaussian Smoothing to remove high-frequency noise
blurred = cv2.GaussianBlur(gray, (5, 5), 0)

# 4. Canny Edge Detection with Dual-Thresholding
edges = cv2.Canny(blurred, threshold1=50, threshold2=150)

# 5. Display result
cv2.imshow("Detected Edges", edges)

Video Stream Processing

Handling real-time camera feeds and video files efficiently.

Real-Time Frame Loop

Video is processed frame-by-frame inside a continuous execution loop until a user escape signal is triggered.

  • cv2.VideoCapture(0) connects to default system camera.
  • source.read() returns boolean status and frame matrix.
  • cv2.waitKey(1) maintains frame rate and polls keyboard events.
  • Always release video capture object to avoid device locking.
webcam_loop.py Real-Time 
cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break
    
    # Flip frame horizontally for mirror effect
    frame = cv2.flip(frame, 1)
    
    # Process frame...
    cv2.imshow("Live Camera", frame)
    
    # Break loop on ESC key (27)
    if cv2.waitKey(1) == 27:
        break

cap.release()
cv2.destroyAllWindows()

Deep Learning with OpenCV (cv2.dnn)

Running high-speed neural network inference with lightweight dependencies.

OpenCV DNN Engine Advantages

  • Zero Extra Heavy Dependencies: Run PyTorch, ONNX, or Caffe models without needing full PyTorch/TensorFlow installs.
  • Pre-processing via blobFromImage: Performs mean subtraction, scaling, and channel swapping in C++.
  • Optimized CPU/GPU Backends: OpenCL, CUDA, Vulkan, and Intel Inference Engine support.
Blob Preprocessing Equation:
blob = (frame - Mean) * ScaleFactor
dnn_inference.py cv2.dnn 
# Load Caffe Prototxt & Weight File
net = cv2.dnn.readNetFromCaffe(
    "deploy.prototxt", 
    "res10_300x300_ssd_iter_140000_fp16.caffemodel"
)

# Create 4D Input Blob
blob = cv2.dnn.blobFromImage(
    frame, 1.0, (300, 300),
    [104.0, 117.0, 123.0],
    swapRB=False, crop=False
)

net.setInput(blob)
detections = net.forward()
